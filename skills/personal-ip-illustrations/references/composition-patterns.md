# Composition Patterns

Choose one structure type. Avoid mixing too many diagram types. For visual variety, pair the structure type with one visual mode from `visual-style-library.md`.

## Structure Types

### Workflow

Use for input -> processing -> output, content production, AI workflows, automation chains.

Draw a left-to-right movement with one orange arrow. Put the boy at the processing point. Let the Bichon carry or push one input item.

### System Part

Use for filters, information sources, a database corner, an agent subsystem, or a local mechanism.

Draw only 3-5 modules. The boy operates one key module. The Bichon guards, nudges, or carries a small signal.

### Before / After

Use for messy -> stable, manual -> automated, scattered -> organized, anxious -> calm.

Draw two simple states with one transition. Avoid symmetrical PPT panels. Let the characters do the transition action.

### Character State

Use for user pain, creator status, tool overload, stuck -> moving.

Draw 2-4 tiny moments. The boy and Bichon may repeat across panels, but keep each panel sparse.

### Concept Metaphor

Use for content machines, thinking wells, trust bridges, idea presses, handoff devices, or strange workstations.

Draw one odd low-tech object and one action. This is the safest default for the personal IP style.

### Method Layers

Use for method frameworks, capability stacks, or system layers.

Draw stacked boxes or physical layers, not a formal pyramid. The boy builds or adjusts one layer while the Bichon fetches a small piece.

### Route Map

Use for learning paths, handoff paths, content journey, or from idea to delivery.

Draw a curved path with a few nodes. The boy walks, pulls, or repairs the path. The Bichon carries a marker or shuttlecock.

### Mini Comic

Use for failure-to-success or a tiny process story.

Use 2-4 panels max. Each panel has one action and little text.

## Original Metaphor Method

1. Convert the abstract idea into a physical action: stuck, leaking, heavy, sorting, fermenting, opening, folding, filtering, repairing, catching, or returning.
2. Convert the system into a low-tech object: box, drawer, press, scale, gate, well, ladder, pipe, spool, switch, turntable, mailbox, hand-crank machine, or odd workstation.
3. Put the boy and Bichon into the action. The boy does the main operation; the Bichon helps with a smaller visible task.

- pull
- push
- carry
- catch
- sort
- weigh

- connect
- patch

The action must explain the idea, not merely look cute.

## Anti-Copy Rule

Do not replicate the existing Xiaohei example compositions directly, including conveyor breakpoints, Xiaohei as a funnel, cutting a fish, the exact handoff path, the exact idea-press layout, the exact information well, the exact fermentation jar, the exact toolbox, or the exact trust bridge. Use them only for visual density and restraint. Invent a fresh physical metaphor for the user's specific concept.
